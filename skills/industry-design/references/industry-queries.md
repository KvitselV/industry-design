# Industry queries

Build queries from the brief. Do not reuse one canned "modern SaaS" search for every project.

Each search needs four angles:

1. **Aesthetic.** Density and material, without a brand name. Examples: `editorial monochrome SaaS landing page`, `ink on newsprint`, `terminal and monospace`, `calm productivity app`, `photo-led brand site`.
2. **Industry.** The category plus the surface. Example: `healthcare clinic membership marketing site`.
3. **Goal.** What the page must do. Example: `developer tool website with product screenshots`, `high-intent waitlist page`, `pricing page with proof beside the plan`.
4. **Peer.** One product the audience already respects. Study a trait, do not clone the brand. Example: `Linear changelog dark developer tool`.

Then open the best matches and write the lock. Browse [Refero Styles](https://styles.refero.design/) when you need to see the spread before naming queries.

## What to notice

Read each full style for role, not for a hex to scatter:

- canvas, raised surface, text, border, accent, and where the accent is allowed
- display type versus UI type, and whether mono is only for code
- density: airy marketing versus a working tool
- how the product is shown: full window, crop, device, diagram, photo
- do and don't lines

Styles do not cover in-app dashboards, settings, auth, or iOS as style systems. For those, lock taste with styles, then search screens and flows.

Screen queries name the object: `billing settings cancellation modal`, `dashboard empty state`, `data table filters`.

Flow queries name the journey: `signup onboarding`, `checkout with promo code`, `subscription cancellation`.

## Category starting points

Use these as the first searches, then replace them with what the brief actually is. They are angles, not palettes.

| Category | Search toward | Usually a miss here |
| --- | --- | --- |
| B2B SaaS | `productivity SaaS with airy spacing`, plus a peer the buyer knows | Identical icon cards and a gradient wash with no product |
| Developer tools | `developer tool website with product screenshots`, `terminal and monospace` | Sparkles, purple, a letter in a colored square |
| Fintech, banking, insurance | `premium fintech website with restrained typography` | Crypto neon, fake precision, playful 3D coins |
| Crypto and web3 | `web3 marketing site tasteful restrained`, then a current product the brief names | Purple mesh gradients as a substitute for a product |
| Healthcare and wellness | `warm trustworthy healthcare product marketing` | Clinical clip-art, low-contrast pastels, cute error copy |
| Security, legal, compliance | `trust-heavy security product marketing`, proof and documentation patterns | Fear graphics, dark-hacker clichés, vague "enterprise grade" |
| Education | `calm learning product marketing`, then the audience's age | Toy UI on a tool for adults, or a dashboard look on a children's product |
| Commerce | `luxury ecommerce editorial product page` or a mass-market peer, chosen from the price | A SaaS hero on a catalog |
| Media and editorial | `ink on newsprint`, `editorial brand site` | Card grids where the writing should lead |
| Hospitality and local | `photo-led hospitality brand site` | Stock-looking interiors, generic "experience" headlines |
| Climate, industrial, hardware | `industrial product site with real materials` | Abstract blob backgrounds where the object should be |
| AI products | `AI product shown as a working surface, no sparkles` | Purple glow, magic-wand icons, "meet your copilot" |
| Marketplaces | `marketplace landing with supply and demand made obvious` | A single-player SaaS story |
| In-app UI | A style for taste, then `dashboard empty state` or the real screen type as a screen search | Marketing type sizes and a hero layout inside the tool |

If the category is not listed, write the four angles from the brief in the same shape. Do not force the work into the nearest row.

## Goal changes the same industry

Hold the industry fixed and change the goal query:

- **Acquire.** One action, the product visible, one proof element near the promise.
- **Explain.** A longer page, the working surface shown, three steps, objections answered.
- **Convert high intent.** Short page, the offer repeated, almost no tour.
- **Compare.** The alternative the searcher already has, then the difference, with sources for every claim.
- **Operate.** Screens and flows. The marketing style does not become the app chrome.

Pick the references that match the goal. A beautiful brand site is the wrong primary reference for a settings screen.
